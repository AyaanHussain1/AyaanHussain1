## What I work on

I build systems end to end — data in, model or retrieval logic in the middle, a working interface out. Most of my recent work sits at the intersection of **LLM applications (RAG)** and **production ML**, not just model training.

- Designing retrieval pipelines: chunking strategy, embedding choice, vector search, and grounding LLM output against real sources instead of hallucinated context
- Shipping ML models past `model.fit()` — into APIs, deployed apps, and multi-surface clients (web, browser extension, desktop)
- Backend architecture for AI products: structured extraction from unstructured input (resumes, transcripts, code), schema-validated LLM output, and scoring/matching logic

**Currently:** deepening RAG evaluation methodology, learning Docker for reproducible deployment, and building the backend of an AI-driven recruitment platform at Ezitech.
